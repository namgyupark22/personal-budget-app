처음 한 번, Google 연결

이 앱은 Google Apps Script 화면을 사용하지 않습니다. Google 계정 승인을 받은 뒤 브라우저에서 시트를 직접 읽고 씁니다.

1. Google 프로젝트 준비

  1. Google Cloud Console에서 개인 가계부 전용 프로젝트를 만드세요.
  2. Google Sheets API를 선택한 프로젝트에서 사용 설정하세요.
  3. Google Auth Platform에서 앱 이름과 본인 이메일을 입력하세요.
  4. 개인 Gmail 계정이면 대상은 외부 사용자로 설정하고, 테스트 사용자에 본인 Google 이메일을 추가하세요. 개인 테스트용으로 시작하면 됩니다.
  5. 데이터 액세스에서 https://www.googleapis.com/auth/spreadsheets 범위를 추가하세요. 이 권한은 Google 계정의 스프레드시트 읽기·쓰기를 허용합니다. 앱은 등록한 연도 파일만 대상으로 사용합니다.

2. 웹 클라이언트 만들기

  1. 클라이언트 → 클라이언트 만들기 → 유형 웹 애플리케이션을 선택하세요.
  2. 승인된 JavaScript 원본에 아래 주소를 그대로 등록하세요. 끝에 경로나 슬래시를 추가하지 않습니다.

    https://namgyupark22.github.io

  3. 생성된 클라이언트 ID(…apps.googleusercontent.com)를 복사하세요. 클라이언트 보안 비밀은 이 앱에 입력하지 않습니다.
  4. 가계부 첫 화면의 클라이언트 ID 칸에 붙여 넣고 Google 계정 연결을 누르세요.

Google의 로그인·권한 승인 화면은 본인이 확인하고 진행하세요. 팝업이 막히면 팝업을 허용해 주세요. 설정 반영까지 잠시 걸릴 수 있습니다.

이후 사용

시트 링크와 클라이언트 ID는 이 브라우저에 저장됩니다. 다른 기기에서는 설정을 다시 입력해야 합니다. 로그인 토큰은 메모리에만 보관하며 새로 열거나 만료되면 다시 연결합니다.

연도별 시트는 설정에서 추가하세요. 홈 화면 바로가기는 새 웹앱 주소로 추가합니다. 기존 Apps Script 앱은 별도로 계속 사용할 수 있습니다.

앱 화면과 코드는 공개되지만 개인 기록은 포함되어 있지 않습니다. Google 계정 연결 후 설정에서 본인 시트 링크와 연도를 등록하세요. 시트 공유 설정은 비공개로 유지하세요. ChatGPT 로그인이나 구독은 필요하지 않습니다.

변경 충돌을 확인한 뒤 저장하지만 Google Sheets의 직접 편집과 저장 전체를 잠그지는 못합니다. 동일 거래를 여러 창·기기에서 동시에 수정하지 마세요. 저장 중 통신이 끊기면 내역을 새로고침해 확인한 뒤 같은 요청을 재시도하세요.

개인정보

거래 내역은 연결한 Google 스프레드시트에 저장합니다. 이 사이트의 서버에 가계부 데이터나 Google 토큰을 별도 저장하지 않습니다. 저장 재시도 확인을 위해 현재 탭의 세션 저장소에 일시적으로 요청을 보관하고, 시트 날짜 셀의 메모에 요청 식별자를 남깁니다. 성공하면 세션의 요청을 지웁니다.

화면의 연결 종료는 이 탭의 토큰과 화면 데이터를 비웁니다. Google 권한 자체를 철회하려면 Google 계정 연결 관리를 이용하세요.
